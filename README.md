# ETS / Flex

Интерфейс командного пространства на **Nuxt 4**, **Vue 3**, **TypeScript** и **Element Plus**. Основная страница: `/main`.

## Разработка

Требуется Node.js 24.

```sh
npm ci
npm run dev
```

Проверка типов: `npm run typecheck`. Статическая сборка: `npm run generate`.
Для проверки пути GitHub Pages: `NUXT_APP_BASE_URL=/flex/ npm run generate`.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает сайт и публикует его после push в `main`. В настройках репозитория **Settings → Pages → Source** выберите **GitHub Actions**. Адрес страницы после успешного deploy: `https://dsh16.github.io/flex/main/`.

Путь ресурсов определяется автоматически из настроек Pages; локально используется `/`.

## Возможности демонстрации

Переключение и создание текстовых каналов, переименование, сообщения, эмодзи, закрепление ссылок, приглашение через копирование адреса, адаптивное меню. Данные хранятся в памяти страницы и сбрасываются при перезагрузке. Прикрепление файла добавляет только его имя. Голосовая связь, загрузка файлов и многопользовательский обмен требуют backend.

## Браузерные проверки

```sh
NUXT_APP_BASE_URL=/flex/ npm run generate
npm run test:e2e
```

Тесты используют Python 3 и Chromium по пути `/usr/bin/chromium` (путь можно изменить в `playwright.config.ts`). Проверяют страницу на desktop/mobile, отправку сообщения, переключение и создание каналов.
